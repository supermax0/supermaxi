# دليل المالك — FINORA Clinics

صفحة واحدة للمتابعة اليومية.

## افحص يومياً

1. **لوحة التحكم** — مواعيد / زيارات / إيرادات اليوم.
2. **الأطباء والجداول** — دوام وإجازات.
3. **المالية** — فواتير ومدفوعات واستثناءات.
4. **المخزون** — إن كان مفعّلاً: نواقص وانتهاء صلاحية.
5. **التقارير** — ملخص أسبوعي حسب الحاجة.

## إعداد مرة واحدة

| عنصر | ملاحظة |
|------|--------|
| وضع المنشأة | عيادة فردية / متعددة أطباء / مركز |
| الصلاحيات | استقبال ≠ طبيب ≠ محاسب |
| الحجز العام | فعّله فقط بعد ضبط الأوقات وOTP |
| النسخ الاحتياطي | تأكد أن الحالة اليومية = SUCCESS |

## لا تفعل أثناء التجربة

- لا تطلب اختصاصاً جديداً كبيراً قبل استقرار التشغيل اليومي.
- لا تعطِ الجميع صلاحية مدير «لتسهيل التجربة».
- سجّل طلبات الميزات كـ P4 في سجل التجربة؛ لا تُنفَّذ تلقائياً.
