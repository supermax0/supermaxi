# دليل الطبيب — FINORA Clinics

صفحة واحدة للزيارة اليومية.

## مسار الزيارة

1. **لوحة / زياراتي** — اختر المريض التالي.
2. **مساحة الطبيب** — ابقَ هنا معظم الوقت.
3. **الزيارة** — شكوى، ملاحظات، علامات حيوية.
4. **الفحص / الاختصاص** — يظهر تلقائياً حسب اختصاص الزيارة (أسنان، أطفال، نسائية، باطنية، قلب…).
5. **وصفة** — أدوية + تعليمات.
6. **متابعة** — تاريخ مراجعة إن لزم.
7. **إكمال** — يُغلق السجل ويجهّز الفوترة.

## تذكير سريري مهم

- مخطط النمو = **تاريخ قياسات** وليس مخطط نسب WHO.
- حقول ECG / Echo = **إدخال الطبيب** وليست تفسيراً آلياً.
- الأمراض المزمنة والأدوية الحالية سجل طولي للمريض — لا تُنشئ محركاً موازياً خارج النظام.

## إن واجهت عائقاً

لا تكمل زيارة على مريض خاطئ. أوقف واطلب من الاستقبال التحقق من الملف، وسجّل المشكلة في الدعم (بدون تفاصيل سريرية في الدردشة العامة).
