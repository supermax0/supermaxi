# دليل الاستقبال — FINORA Clinics

صفحة واحدة لليوم الأول.

## يوم عادي

1. **مريض جديد / بحث** — من المرضى أو الاستقبال؛ ابحث بالاسم أو الهاتف قبل إنشاء ملف جديد.
2. **حجز موعد** — طبيب + اختصاص + خدمة + وقت متاح.
3. **وصول** — تأكيد / تسجيل حضور → يظهر في الطابور.
4. **تسليم للطبيب** — المريض يظهر في زيارات الطبيب / مساحة الطبيب.
5. **فاتورة** — بعد إكمال الزيارة أو حسب سياسة العيادة؛ استلام دفعة إن لزم.

## اختصارات مفيدة

| الهدف | أين |
|--------|-----|
| طابور اليوم | الاستقبال / الطابور |
| إعادة جدولة | المواعيد |
| رصيد مريض | ملف المريض → المالية |

## تجنّب

- لا تنشئ مريضاً مكرراً إن وُجد نفس الهاتف.
- لا تمنح صلاحية مدير للجميع.
- إن فشل الحجز العام، سجّل الوقت والخطأ في سجل الدعم دون بيانات سريرية حساسة.
