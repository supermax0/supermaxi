# قائمة الفحص اليدوي — Finora Food POS

نفّذ البنود على شركة تجريبية من نوع `food_wholesale_retail`، ودوّن رقم الفاتورة وحركة المخزون لكل عملية بيع أو مرتجع.

## الباركود والمنتجات

- [ ] 1. مسح باركود قطعة يضيف سطرًا واحدًا مباشرة ويعيد التركيز للبحث.
- [ ] 2. مسح الباركود نفسه خمس مرات ينتج كمية 5 في سطر واحد.
- [ ] 3. تبديل الوحدة بين قطعة/باكيت/كارتون يغير السعر والتحويل والتحقق.
- [ ] 4. مسح باركود الكارتون يختار الكارتون تلقائيًا بلا نافذة تأكيد.
- [ ] 5. بيع مفرد يستخدم سعر المفرد المحفوظ في الخادم.
- [ ] 6. بيع جملة يستخدم سعر الجملة المحفوظ في الخادم.
- [ ] 7. بلوغ حد الجملة يحول السعر تلقائيًا ويظهر إشعارًا صغيرًا.
- [ ] 8. فاتورة مختلطة تحتفظ بوضع التسعير لكل سطر.
- [ ] 9. بيع 1 كارتون + 2 باكيت + 3 قطع يخصم مجموع الوحدات الأساسية الصحيح.
- [ ] 10. طلب كمية أعلى من الرصيد يعطل الدفع ويعرض المتاح بصيغة الوحدات.

## العميل والدفع

- [ ] 11. البيع لعميل نقدي لا يتطلب إنشاء عميل.
- [ ] 12. البيع الآجل يرفض العميل النقدي ويقبل عميلًا حقيقيًا.
- [ ] 13. تجاوز حد الائتمان يُرفض أو يُسمح فقط بصلاحية التجاوز.
- [ ] 14. الدفع النقدي يسجل قيمة الفاتورة لا المبلغ المستلم كله.
- [ ] 15. الدفع المختلط يقبل مجموعًا يساوي الإجمالي فقط.
- [ ] 16. المبلغ المستلم الأكبر يعرض الباقي ولا يسجله كدفعة.

## الاستمرارية والمرتجعات

- [ ] 17. تعليق السلة لا يخصم المخزون.
- [ ] 18. استرجاع المعلقة يعيد العميل والوحدات والأسعار والخصومات والملاحظات ثم يعيد التحقق.
- [ ] 19. المرتجع الكامل يعيد المخزون والدفعات ويصفر صافي البيع في التقرير.
- [ ] 20. خصم السطر يعمل ضمن الصلاحية والحد الأعلى للدور.
- [ ] 21. خصم الفاتورة يعمل ضمن الصلاحية والحد الأعلى للدور.
- [ ] 22. دفعة منتهية لا تدخل في الصرف.
- [ ] 23. FEFO يستهلك الأقرب انتهاءً أولًا، ويعيد المرتجع لنفس الدفعات قدر الإمكان.

## الوزن والتزامن والتوافق

- [ ] 24. باركود الميزان المكوّن حسب الإعدادات يحدد المادة والوزن تلقائيًا.
- [ ] 25. كمية 1.250 لوحدة الوزن تُحفظ وتُطبع وتُرتجع دون تقريب.
- [ ] 26. كاشيران يبيعان آخر رصيد بالتزامن: تنجح عملية واحدة فقط عند سياسة المنع.
- [ ] 27. النقر المزدوج أو إعادة الطلب بالمفتاح نفسه لا ينشئ فاتورتين.
- [ ] 28. فشل فتح نافذة الطباعة لا يلغي الفاتورة الناجحة، وتعمل إعادة الطباعة.
- [ ] 29. منتج قديم أحادي الوحدة يظهر ويباع من الكاشير الجديد.
- [ ] 30. فاتورة قديمة تبقى قابلة للعرض والطباعة والتقرير دون إعادة تفسير السعر أو التحويل.

## فحص الأجهزة والأداء

- [ ] قارئ باركود فعلي أو محاكاة لوحة مفاتيح سريعة مع Enter.
- [ ] لوحة مفاتيح: F2 وF3 وF4 وF7 وF8 وF9 والأسهم وEscape.
- [ ] شاشة لمس: أهداف اللمس، تعديل الكمية، السلة والدفع.
- [ ] Desktop وTablet وMobile؛ السلة ثابتة على الكبير وBottom Sheet على الصغير.
- [ ] كتالوج 10,000 منتج و50,000 نوع: أول صفحة فقط تُحمّل، والبحث/الباركود لا يجمّدان الواجهة.
- [ ] فحص سجل الخادم والواجهة بعد كل سيناريو وعدم وجود أخطاء 500 أو أخطاء JavaScript.
