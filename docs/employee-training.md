# أكاديمية الموظف

المسار داخل النظام: `/employee-desk/training`، من الرئيسية أو الحساب في مكتب الموظف.
يستخدم نفس الجلسة وصلاحية `use_employee_desk`، ولا يضيف صلاحيات جديدة.

- ٧ دروس: الدخول، الرسائل، الرد، الحجز، معرفة المنتجات، أسلوب الرد، وتمرين حجز.
- ١٧ لقطة PNG من قوالب المكتب الحقيقية بحجم 390×760. العملاء والرسائل والمنتج داخل الصور بيانات توضيحية.
- مناطق الضغط نسب مئوية في `static/employee_desk/training/lessons.json`، مع الشرح والتلميحات.
- الكتالوج يقرأ المنتجات المفعّلة والظاهرة في نقطة البيع ضمن نفس نطاق المكتب، مع الوصف والمواصفات العامة وأسعار البيع. الحقول مسموحة بقائمة محددة، وأسعار شراء الألوان محجوبة.
- التدريب يرسل طلبات GET فقط. الردود ونموذج الحجز النهائي تمارين محلية؛ لا تسجيل عميل أو فاتورة ولا إرسال رسالة.
- التقدّم محفوظ محلياً لكل شركة وحساب ومتصفح. لا يوجد تقرير تقدّم مركزي للمدير، ولا تُحفظ بيانات نماذج التدريب.
- اختبار الرد النهائي يتحقق من اكتمال المعلومات والسعر؛ مراجعة الأسلوب والمحتوى النهائي مسؤولية المشرف.

## تحديث الصور عند تغيير واجهة المكتب

من مجلد المشروع، شغّل الخادم التجريبي المستقل:

```powershell
py tests/support/employee_training_preview.py
```

وبنافذة ثانية:

```powershell
node scripts/capture_employee_training.mjs
```

الالتقاط يستخدم Chrome المثبت وPlaywright الموجود بالمشروع، ويصل حصراً للخادم المحلي `127.0.0.1:5099`. يعيد إنشاء الصور وإحداثياتها من القوالب الحالية. خادم المعاينة بياناته وهمية ولا يستورد تطبيق الإنتاج أو قواعد بياناته.

## التحقق

```powershell
py -m pytest tests/test_employee_desk_training.py tests/test_employee_desk_permission_bridge.py -q
node node_modules/@playwright/test/cli.js test tests/employee-desk-training.spec.js --workers=1 --reporter=list
```

اختبارات المتصفح تحتاج خادم المعاينة أعلاه. تشمل الضغط على الصور، الاختبارات والتقدّم، قراءة السعر بالأرقام العربية، غياب أي طلب كتابة، حالات خطأ الكتالوج، النصوص غير الآمنة، أحجام الهاتف والكمبيوتر، وتعطل التخزين المحلي. اختبارات Python تستخدم قاعدة SQLite في الذاكرة لفحص الصلاحيات وحدود بيانات البيع.
