# FINORA — صوت الكتابة

أضيف حسب طلب المستخدم صوت مستقل للكتابة إلى منظومة أصوات الواجهة الموجودة. تحديث واجهة محلي فقط، دون تعديل السيرفر أو العمليات المالية والمخزون.

## السلوك

- نقرة أصلية هادئة عبر WebAudio، مدة الوصفة28ms وذروة0.038 عند100%؛ الافتراضي يبقى30%. أخف من صوت الزر، ويعمل دون إنترنت.
- يشمل الحروف العربية واللاتينية والأرقام والمسافة والمسح في حقول النص والبحث وكلمة المرور والعدد، وفيtextarea والنص القابل للتحرير. لا يحتفظ بالمفاتيح أو النصوص أو كلمات المرور.
- اختصارات Ctrl/Alt/Meta والأسهم والتكرار المستمر وتركيبIME والعناصر المعطلة أو للقراءة فقط صامتة. التغيير البرمجي للحقول لا يعزف نغمة.
- تأخير65ms يكشف دفعات قارئ الباركود: ثلاثة مفاتيح أو أكثر بفواصل≤50ms تكتم نقرات الدفعة. Enter أو تغيير التركيز أو إغلاق الواجهة يلغي النقرات المنتظرة. هذا كشف سرعة، ولذلك الكتابة البشرية المتواصلة بهذه السرعة العالية قد تُكتم أيضاً. لا يغير محتوى الحقل أو يمنع الحدث أو يغيّر عمل المسح.
- الصوت لا يخضع لحد140ms الخاص بتكرار نغمات الأزرار؛ الكتابة العادية تعزف لكل مفتاح. حدأربع أصوات متزامنة يبقى قائماً.
- **الإعدادات ← الأصوات ← صوت الكتابة**: مفتاح مستقل ومعاينة وشرح`?` بنمطFINORA. يبدأ مفعلاً حتى للتفضيلات القديمة التي لا تحتوي خيارالكتابة، ويحفظ مستقلاً عن الكتم العام. الكتم العام ومستوى0 يشملانه.

## التحقق

-13/13 اختباراً مركزاً: العربية والإنكليزية والأرقام والمسح، الحقول السرية دون قراءةقيمها، حقولtextarea والمحتوى القابل للتحرير، كشف دفعات الباركود، استئناف الكتابة بعدها، الاختصارات والعناصر غيرالقابلةللتحرير، إلغاء النغمة بعد الإغلاق، الكتم المستقل والتفضيلات القديمة.
- اختبارElectron الحقيقي ناجح: خمسة أحرف بخمس نقرات فعلية منAudioContext، نقرةالمسح، صمت12حرفاً من دفعةالمسح، عدم إصدار صوتلملء الحقول برمجياً، وحفظ مفتاح الكتابة بعد إعادةالتشغيل. رُسمت النغمات العشر بالمولد الإنتاجي نفسه فيOfflineAudioContext؛ نغمةالكتابة ذروة0.037774 ومدةمسموعة≈21ms، بلاقص.
- نجحت اختبارات الواجهة العامة320/320 في48 ملفاً، بخروج0. فحوص TypeScript للواجهة وElectron وE2E، وESLint والتنسيق والبناء ناجحة.
- صورةالإعدادات راجعت بصرياً: `tests/_artifacts/interface-sounds-20261013/sound-settings.png`، ومقاييسالصوت `audio-metrics.json` في نفسالمجلد.
- إعادة تشغيلFINORA الفعلي تمت بإغلاق طبيعي ثم فتح طبيعي. `live-typing-installed.json` يثبت نافذةالتطبيق وحزمةالكتابة المستخدمة دون خياراتتصحيح.

نجحت فحوص Electron العامة50/50 بخروج0 في9.1 دقيقة، وتشمل البيع والأوفلاين والطباعة والعملاء والموظفين والجرد والموردين. سجلات الفحوص العامة لهذا التحديث في `tests/_artifacts/erp-regression/20261013-typing-sounds`. اختبارات Python والسيرفر لم تُعد لأن التغيير محصور في أصوات واجهة Desktop.
