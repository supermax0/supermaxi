# FINORA — عمليات المخزون الأصلية، 13 أكتوبر 2026

التحويل بين الفروع يستهلك دفعات FIFO الحقيقية ويثبت كلفتها. قيمة الشركة تشمل القطع قيد النقل وتبقى ثابتة خلال الإرسال والاستلام. الإلغاء يرجع الكلفة والكمية الأصليتين. توجد مقارنة حالة شرطية قبل تغيير الرصيد، ومقارنة نسخة المخزون قبل التلف، وحماية حجز الأجهزة. لا يحوّل نقص إثبات الكلفة إلى سعر شراء تخميني.

التلف يكتب قيد خسارة مخزون غير نقدي متوازن؛ العكس سند جديد مرتبط بالأصل. لا ينشئ Expense أو AccountTransaction أو حركة صندوق. الخسارة والعكس يظهران في القيود والتقارير وقائمة الدخل وطباعة التقرير وتصديره، ضمن الفرع المصرح به. أصل السند ودليل الكلفة محميان من التعديل والحذف المباشر بآلية ORM ومحفزات SQLite. الكلفة تلتزم بمجال المبالغ المحاسبية ولا تتقرب في JavaScript.

أوامر التغيير تحتاج اتصالاً وتحقق جلسة حية؛ يحفظ main الطلب مشفراً قبل POST، ويراجع نفس UUID بعد فقدان الرد أو إعادة التشغيل. سجل المخزون مفصول بنطاقه عن سجل طلبات العملاء، ولا يعاد الإرسال المالي تلقائياً دون اتصال. رفض الصلاحية أو تغيير الشركة/الفرع يمنع الاستعادة. إذا فشل الحفظ المشفر لا يرسل الطلب. الموقع وبقية أدوات الشاشة تقفل أثناء فتح نموذج العملية لتجنب تغيير الهدف خلف النموذج.
