## التنفيذ والتحقق

- إعادة استخدام الخدمات الأصلية؛ جداول سير العمل لا تصبح دفاتر أرصدة أخرى.
- كل كتابة مالية ومخزنية ذرية، مقيدة بالشركة والفرع والصلاحية، ذات مفتاح إعادة إرسال ثابت ونسخة لمنع التعديل على حالة أحدث.
- اختبارات خدمات حقيقية بقواعد معزولة، ثم واجهة وأنواع وتنسيق وبناء، ثم Electron والطباعة وثلاثة مقاسات، ثم Python وDesktop وElectron العامة بعد آخر تعديل.
- يحتفظ كل تسليم بنطاقه ونتائجه وحدوده. وجود شاشة أو نجاح اختبارات مختارة لا يعني اكتمال الميزة أو ERP.
- النشر يأتي بعد تجهيز حزمة قابلة للمراجعة ونسخة احتياطية والتحقق؛ لا تُستخدم بيانات الشركة لتجربة قبض أو رد أو تسوية.
