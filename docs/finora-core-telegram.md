# قناة بوت تلگرام — FINORA CORE 0.1.5

من **الإعدادات → بوت تلگرام** تگدر تربط البوت، تفحص اتصاله أو تفصله مع الاحتفاظ بالمحادثات. التصميم يستخدم نفس بطاقات FINORA والأزرار والأيقونات الحالية؛ تلگرام يظهر أيضاً حول الكرة الرئيسية وفي فلتر المحادثات.

## الربط

1. افتح [BotFather الرسمي](https://t.me/BotFather) واستعمل `/newbot` لإنشاء بوت FINORA.
2. حدّث خادم FINORA بهذه الملفات، وثبّت نسخة FINORA CORE 0.1.5. تعديل تطبيق سطح المكتب وحده لا يضيف المسارات للخادم المنشور.
3. افتح قسم **بوت تلگرام**. إذا حساب FINORA الداخلي غير مهيّأ، اضغط **تهيئة قنوات FINORA على الخادم**. الحساب الجديد يبدأ بوضع المراجعة وتكون الردود التلقائية متوقفة.
4. أدخل الرمز في **رمز بوت تلگرام** واضغط **ربط البوت**. لا ترسله بالمحادثات. يتحقق الخادم من هوية البوت، يضبط Webhook مع سر تحقق مستقل ثم يفحص عنوانه قبل إعلان نجاح الربط. الرمز محفوظ مشفراً ولا ترجع قيمته للإدارة أو سجلات النشاط.
5. اضغط **فحص اتصال تلگرام**. افتح رابط البوت من حساب عميل واضغط **بدء / Start**، ثم أرسل رسالة.
6. اختَر طريقة الرد من **ردود العملاء**: تلقائي، مراجعة، أو يدوي. القناة تستعمل نفس النموذج المحلي/السحابي ومعرفة FINORA، وتلتزم بإيقاف الأتمتة وتدخل الموظف.

الخادم يحتاج HTTPS عام وشهادة صالحة. عنوانه يؤخذ من `FINORA_CORE_PUBLIC_URL` ثم `BASE_URL`، مع القيمة الافتراضية `https://www.finora.company`. لا يُستخرج من Host المرسل بالطلب. يجب تمرير الترويسة `X-Telegram-Bot-Api-Secret-Token` إلى التطبيق عبر الوكيل العكسي. لا يحتاج الربط Meta App ID أو صلاحيات Meta.

لعنوان FINORA يُسجّل `www.finora.company` مباشرة حتى إذا كانت قيمة `BASE_URL` هي `finora.company`، لأن تحويل 301 يمنع تلگرام من تسليم التحديثات. حالة تسجيل Webhook وحدها لا تثبت وصول رسالة؛ راجع فحص الاتصال وآخر استقبال. العناوين المخصصة لا تُعدّل.

## السلوك والحدود

- يستقبل **المحادثات الخاصة** فقط؛ لا يعالج رسائل المجموعات والقنوات أو رسائل البوتات أو تعديل الرسائل السابقة.
- هوية العميل هي معرّف مستخدم تلگرام المصادق عليه في الرسالة (`telegram_user_id`). الاسم واسم المستخدم ومعلومات الرسائل المحوّلة لا تثبت ملكية حساب شركة ولا تربط العميل بشركة أخرى تلقائياً.
- النص والصورة والفيديو والفويز والملفات الواردة تدخل المحادثة. تنزيل مرفقات Bot API العام محدود إلى 20 MB؛ الروابط المحتوية رمز البوت لا تدخل بيانات المحادثة أو النموذج أو واجهة التطبيق. المرفقات الكبيرة تُسجّل كغير مدعومة.
- الصور والفيديو والصوت تستعمل التحليل الموجود في FINORA؛ توفر التحليل يعتمد على إعداد النموذج وأدوات الوسائط في الخادم. إرسال الصور والفيديو والفويز اليدوي يستعمل رفع الملف مباشرة إلى تلگرام بعد معالجة الوسائط الحالية.
- استشارة النشاط وتجهيز الحساب وإخفاء الصفحات وتعديل الصلاحيات تستعمل المسار الحالي نفسه: اقتراح موثّق وموافقة المشرف، وتنفيذ داخل حساب العميل المرتبط بالمحادثة. كلمة المرور لا تُرسل داخل محادثة البوت.
- التحديثات المكررة لا تُكرر الرسالة أو تشغيل الذكاء. معرّف رسالة تلگرام يُخزّن مع معرّف المحادثة؛ رقم الرسالة نفسه في محادثتين لا يتصادم.
- حظر عميل للبوت يُسجّل فشل الإرسال لهذا العميل؛ لا يجعل قناة البوت كلها فاقدة الصلاحية. أخطاء الشبكة وحدود السرعة تدخل إعادة المحاولة الحالية.
- **فصل البوت** يحذف Webhook دون إسقاط التحديثات المعلقة، ويمنع الاستقبال والإرسال بهذه القناة. المحادثات تبقى محفوظة. ربط بوت مختلف يتطلب فصل البوت الحالي ويحفظ هويتي القناتين مستقلتين.

## مسارات الإدارة

كل مسارات الإعدادات تتطلب `settings.manage`:

| الطريقة | المسار تحت `/api/v1/finora-core` | الغرض |
|---|---|---|
| GET | `/settings/telegram` | حالة البوت وبياناته العامة فقط |
| POST | `/settings/telegram/connect` | ربط `{ "botToken": "..." }` |
| POST | `/settings/telegram/health-check` | فحص الرمز وWebhook |
| POST | `/settings/telegram/disconnect` | فصل البوت |
| POST | `/webhooks/telegram/<key>` | استقبال خاص، يتطلب سر الترويسة، محصور بحساب FINORA الداخلي |

لا يوجد تغيير مطلوب في مخطط قاعدة البيانات؛ يستعمل حقول القنوات والمرفقات المشفرة الموجودة.

## التحقق

`tests/test_finora_core_telegram.py` يفحص الربط والتشفير والتحقق من المصدر وتكرار الرسائل وحالة الاتصال والوسائط والمحادثة الاستشارية وإنشاء حساب بعد الموافقة وتخصيصه. الشبكة إلى تلگرام محاكاة داخل الاختبار؛ التنفيذ داخل Flask والذكاء وقاعدة البيانات ومسار الموافقات حقيقي ومعزول.

اختبارات الواجهة في `src/settings/TelegramSettings.test.tsx` و`e2e-settings/telegram.spec.ts` تفحص إخفاء الرمز وتفريغه بعد الربط وفشل الاتصال والشكل والفلتر على 1280×720.

**الاختبار مع بوت حي لم يُنفّذ بدون رمز بوت حقيقي وإضافة التحديث إلى الخادم المنشور.**

مرجع النقل والحدود: [Telegram Bot API](https://core.telegram.org/bots/api).
